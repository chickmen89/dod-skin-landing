# dod skin landing page

Static copy of https://wondrous-bavarois-9e40e2.netlify.app/ captured on 2026-11-11.

## Files

- `index.html`: Original page content, inline CSS and SVG animation.
- `images/`: Four original physician portraits, stored locally.

The Netlify-injected hosting comment and HUD script were removed. Google Fonts and the original external consultation/contact links are retained. No build step is required.

## Preview

Open `index.html` in a browser, or run `python -m http.server 8080` in this directory and visit http://localhost:8080/.

## Hosting

The repository root can be served by any static host, including GitHub Pages. To use GitHub Pages, select **Settings > Pages > Deploy from a branch > main > / (root)**. Uploading this repository does not itself enable Pages.
